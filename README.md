# 칠판 수학

한 문제를 3~5분 동안 칠판에 적어 가며 풀어 주는 수학 강의 웹앱이에요. Claude 없이 혼자 돌아가요.

- 손글씨가 써지면서 그림이 그려지고, AI 목소리로 해설해요. 자막도 나와요.
- 휴대폰으로 문제 사진을 찍으면 AI가 강의를 만들어요. 키 없이 **AI 연결하기** 버튼 한 번으로 연결돼요.
- 홈 화면에 추가하면 앱처럼 열려요. 인터넷이 없어도 이미 만든 강의는 볼 수 있어요.
- 학생에게는 **공유 링크**를 카톡으로 보내면 끝이에요. 학생 쪽에서는 설치하거나 가입할 필요가 없어요.

---

## 0. AI 연결하기 — 버튼 한 번 (키 필요 없음)

**+ 새 강의** 화면에서 **AI 연결하기** 버튼을 누르면 끝이에요.

- 처음 한 번만 무료 **Puter** 계정으로 로그인하는 창이 떠요. 로그인하면 휴대폰이 기억해서, 다음부터는 사진만 찍으면 강의가 만들어져요.
- AI 목소리도 같이 켜져요. 학생도 강의 화면의 **목소리 · 바꾸기 → AI 연결하기**를 누르면 AI 목소리로 들을 수 있어요. 누르지 않으면 휴대폰 기본 목소리로 읽어요.
- 사용량은 로그인한 사람의 Puter 계정에서 나가요. 매달 무료 사용량이 있고, 다 쓰면 앱이 알려 줘요.
- 연결을 끊으려면 새 강의 화면의 **연결 끊기**를 눌러요.

### (선택) 선생님 서버에 키를 넣어 두면

서버에 키가 있으면 버튼 없이 바로 서버로 연결되고, 사용량은 선생님 키에서 나가요.
AI 키는 **선생님 서버(Vercel) 한 곳에만** 넣어요. 휴대폰이나 학생 쪽에는 키가 없어요.

- 앱은 열리면 스스로 선생님 서버를 찾아요. 연결되면 **새 강의** 화면에 "선생님 서버에 연결됐어요"가 나와요.
- 처음 한 번만 **강의 만들기 비밀번호**(`APP_PASSCODE`)를 넣으면, 그다음부터는 사진만 찍으면 돼요.
- 키가 바뀌거나 사용량이 끝나도 **서버에서 키만 바꾸면** 모든 휴대폰에 바로 적용돼요.

### 휴대폰에서 `index.html` 파일로 열 때

파일로 열어도 선생님 서버에 연결돼요. 단, 배포한 주소를 파일 안에 넣어 둬야 해요.

```
cd src
python3 build.py --server https://chalk-math.vercel.app
```

이렇게 만든 `index.html`을 휴대폰에서 열면 서버 주소를 몰라도 바로 연결돼요.
주소를 넣지 않은 파일은 주소 뒤에 `?server=https://chalk-math.vercel.app`를 붙여 한 번 열면 기억해요.

> 파일로 열면 **공유 링크**는 쓸 수 없어요. 학생에게 보내려면 배포 주소로 열어 주세요.
> 서버 없이 직접 키를 쓰고 싶은 분은 **새 강의** 화면 아래 **고급 설정: 내 AI 키로 쓰기**를 누르면 돼요. 그 키는 그 기기에만 저장돼요.

## 1. Vercel에 올리기

### 방법 A — GitHub로 올리기 (추천)

1. GitHub에서 새 저장소를 만들어요. 이름은 예를 들어 `chalk-math`로 해요.
2. 저장소 화면에서 **Add file → Upload files**를 누르고, 이 폴더 안의 파일과 폴더를 **전부** 끌어다 놓은 뒤 Commit해요.
   (`index.html`, `api`, `icons`, `lectures`, `manifest.webmanifest`, `sw.js`, `vercel.json`, `package.json`, `README.md`)
3. vercel.com → **Add New… → Project** → 방금 만든 저장소를 **Import**해요.
4. Framework Preset은 **Other**로 두고, 나머지는 그대로 둔 채 **Deploy**를 눌러요.

### 방법 B — 명령어로 올리기

이 폴더에서 아래처럼 실행해요.

```
npx vercel          # 처음 한 번: 로그인·프로젝트 연결
npx vercel --prod   # 실제 주소로 배포
```

## 2. (선택) 서버에 AI API 키 넣기 — 넣지 않아도 ‘AI 연결하기’ 버튼으로 쓸 수 있어요

Vercel 프로젝트 → **Settings → Environment Variables**에서 아래 **셋 중 하나**만 넣으면 돼요.

| 이름 | 어디서 받나요 | 기본 모델 |
|---|---|---|
| `GEMINI_API_KEY` | Google AI Studio (aistudio.google.com) → Get API key | `gemini-flash-latest` |
| `OPENAI_API_KEY` | platform.openai.com → API keys | `gpt-5.6-terra` |
| `ANTHROPIC_API_KEY` | console.anthropic.com → API Keys | `claude-sonnet-5-5` |

키를 넣은 뒤에는 **Deployments → 맨 위 배포 → ⋯ → Redeploy**를 눌러야 적용돼요.

> 키는 이 화면에만 넣어요. 앱이나 휴대폰에는 넣지 않아요. 키를 바꿀 때도 여기서 바꾸고 Redeploy만 하면 돼요.

### 더 넣을 수 있는 설정 (선택)

| 이름 | 하는 일 |
|---|---|
| `APP_PASSCODE` | **꼭 넣어 주세요.** 넣어 두면 이 비밀번호를 아는 사람만 새 강의를 만들 수 있어요. 학생들은 강의를 보기만 하고, 선생님 API 사용량은 안전하게 지켜져요. |
| `GEMINI_MODEL` / `OPENAI_MODEL` / `ANTHROPIC_MODEL` | 모델을 바꿀 때 써요. "모델을 찾지 못했어요"라는 오류가 나오면 지금 쓸 수 있는 모델 이름으로 바꿔 주세요. |
| `AI_PROVIDER` | 키를 여러 개 넣었을 때 쓸 AI를 골라요: `gemini`, `openai`, `anthropic` 중 하나 |
| `ALLOWED_ORIGINS` | 다른 주소에 올린 앱에서도 이 서버를 쓰게 하려면 그 주소를 쉼표로 넣어요. 같은 주소와 휴대폰 파일(`index.html`)은 넣지 않아도 돼요. |

> 무료 사용량과 요금은 각 회사 정책에 따라 바뀌어요. 쓰기 전에 사용량 화면을 한 번 확인해 주세요.

## 2-1. 목소리 (AI 목소리)

- Gemini 또는 OpenAI 키가 있으면 해설을 **AI 목소리**로 읽어요. 사람처럼 자연스러워요. Claude API 키로는 목소리를 만들 수 없어서 휴대폰 기본 목소리로 읽어요.
- 강의 화면의 **목소리 · 바꾸기**에서 목소리를 고르고 **▶ 듣기**로 미리 들어 볼 수 있어요.
- 문장마다 처음 한 번만 만들고 그 기기에 저장해 둬요. 같은 강의를 다시 보면 사용량이 들지 않아요.
- 사용량 한도에 걸리거나 인터넷이 끊기면 그 문장만 휴대폰 기본 목소리로 대신 읽고, 강의는 멈추지 않아요.
- Vercel 서버에 키를 넣어 두면, 링크를 받은 학생도 키 없이 AI 목소리로 들어요. 이때 사용량은 서버 키에서 나가요.
  학생 수가 많아서 사용량이 걱정되면 환경 변수 `TTS_OFF`를 `1`로 넣으세요. 그러면 학생 쪽은 휴대폰 기본 목소리로만 읽어요.

## 3. 휴대폰에 설치하기

- **아이폰**: 사파리로 배포 주소를 열고 → 아래쪽 **공유** 버튼 → **홈 화면에 추가**
- **안드로이드**: 크롬으로 열면 앱 첫 화면에 **설치** 버튼이 나와요. 안 나오면 크롬 메뉴(⋮) → **홈 화면에 추가**
- 카카오톡 안에서 열었을 때 카메라가 안 되면, 오른쪽 위 메뉴의 **다른 브라우저로 열기**를 눌러 주세요.

## 4. 쓰는 법

- **새 강의**: 첫 화면의 **사진 찍어서 강의 만들기** → 찍으면 바로 만들기가 시작돼요. 보통 30초~2분 걸려요.
- **학생에게 보내기**: 강의 화면의 **공유 링크** → 카톡이나 문자에 붙여 넣기. 링크 안에 강의가 통째로 들어 있어서 서버 없이 열려요.
- **백업·옮기기**: **파일로 저장**하면 `.json` 파일이 생겨요. 다른 기기의 첫 화면 아래 **강의 파일 가져오기**로 넣으면 돼요.
- 내가 만든 강의는 **그 기기 브라우저에만** 저장돼요. 브라우저 기록을 지우면 사라지니까, 아끼는 강의는 파일로 저장해 두세요.

### 모든 학생에게 강의를 기본으로 보여 주고 싶다면

`lectures/library.json`에 강의를 넣고 다시 배포하면, 앱을 여는 모든 사람의 첫 화면에 **공유 강의**로 나와요.

```json
[
  { "title": "...", "unit": "...", "answer": "...", "tip": "...", "points": {}, "chapters": [] },
  { "title": "...", "...": "..." }
]
```

→ **파일로 저장**으로 받은 `.json` 파일의 내용을 대괄호 `[ ]` 안에 쉼표로 이어서 붙여 넣으면 돼요.

## 5. 파일 구성

| 파일 | 하는 일 |
|---|---|
| `index.html` | 앱 전체 (화면, 칠판 플레이어, 사진 올리기) |
| `src/` | `index.html`을 만드는 원본. `python3 src/build.py --server 주소`로 서버 주소를 넣어 다시 만들어요 |
| `api/generate.js` | 사진 → AI → 강의 대본. 키는 여기서만 써요 |
| `api/tts.js` | 해설 문장 → AI 목소리 (서버에 키가 있을 때) |
| `lectures/library.json` | 모두에게 보여 줄 공유 강의 (처음엔 비어 있어요) |
| `manifest.webmanifest`, `sw.js`, `icons/` | 홈 화면 설치·오프라인용 |
| `vercel.json` | AI 답을 최대 5분까지 기다리도록 설정 |
