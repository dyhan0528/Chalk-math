    새 문제 강의 만들기

    문제 사진을 올리면 AI 선생님이 칠판 강의 대본을 써요. 그림 그리기, 핵심 아이디어, 한 줄씩 계산, 정답과 요령까지 3~5분 강의로 만들어 줘요. 30초~2분쯤 걸려요.

    AI 키 넣기

    AI API 키를 넣으면 이 휴대폰에서 바로 강의를 만들 수 있어요. 키는 이 기기에만 저장되고, 고른 AI 회사로만 보내져요.

    1. ① 구글에서 키 받기 ↗구글 로그인 → Create API key → 복사
    2. 붙여 넣으면 자동으로 저장돼요
    모델 바꾸기 (보통은 비워 두세요)
    카메라로 찍기 사진 고르기
    찍으면 바로 강의 만들기가 시작돼요 사진을 여기에 끌어다 놓거나 붙여 넣어도 돼요
    다시 찍기다른 사진
    카메라가 바로 열리지 않으면 사진 고르기 버튼을 눌러 보세요. 고르는 창에서 사진 찍기를 고를 수 있어요. 카카오톡 안에서 열었다면 오른쪽 위 메뉴의 다른 브라우저로 열기를 눌러 주세요.
    문제를 읽는 중…

    • 사진은 문제 하나만 나오게 잘라 주면 더 정확해요. 그림이 있으면 그림까지 나오게 찍어 주세요.
    • 만든 강의는 이 기기의 강의 목록에 저장돼요. 대본이 마음에 들지 않으면 지우고 다시 만들면 돼요.
    • AI가 만든 풀이는 틀릴 수 있어요. 학생에게 보내기 전에 한 번 확인해 주세요.
